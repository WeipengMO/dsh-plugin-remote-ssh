# 故障排查

- **界面与服务端版本不一致**：完全退出并重新启动 DSH Desktop；刷新页面不会重载 Host 缓存的插件模块。
- **首次连接要求主机密钥**：通过服务器控制台或其他可信渠道核对完整 SHA-256 指纹。指纹变化时先查明原因，不要绕过校验。
- **SSH 连接或浏览目录失败**：在设置页测试连接，检查 SSH Config、用户名、私钥和代理。目录必须存在并允许访问。
- **远端 DSH 启动失败**：检查 Linux Node.js ≥24.9、Git、DSH CLI 或 npm 可访问性，及 SSHD 的 `AllowTcpForwarding`。远端私有启动日志可能含认证令牌，分享前应删除。
- **页面断线**：在该远程页面点击 **重新连接**；服务器上的持久会话仍由 Linux DSH 保存。检查 SSH 和远端 DSH 状态，不要把服务监听到公网。
- **Windows 的 Git 面板不显示 Linux 内容**：打开远程 DSH 页面并使用其中的 Git 面板。本地和远端是独立会话，旧占位目录没有自动迁移。

更多使用说明见 [远程 DSH](remote-dsh-host.md)。

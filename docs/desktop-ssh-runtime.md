# 旧 SSH 工作区兼容性

旧版可在 Windows 本地注册占位目录，把该目录下的文件、Shell 与终端请求桥接到 SSH 服务器。这种模式的 Git、worktree、沙箱和文件监视不保证与完整 Linux DSH 等价；本地与远程路径也不是同一文件系统。

为避免升级后已有工作区失效，插件暂时保留这些桥接与已有映射。新建项目和设置页的远程入口改为打开独立 Linux DSH，不再创建占位目录。旧工作区和会话不会自动迁移：在新界面选择同一个 Linux 目录后，使用远端 DSH 自己的工作区和会话。

SSH Host 从保存的配置或 `~/.ssh/config` 选择；首次访问仍需通过可信渠道核对主机密钥。修改或删除 Host 会关闭属于它的隧道。更多操作见 [远程 DSH 使用说明](remote-dsh-host.md)。
